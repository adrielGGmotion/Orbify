# ✧ Orbify

<img src="design/icon.png" width="100" align="right" alt="Orbify icon">

Orbify opens [Discord Quest Home](https://discord.com/discovery/quests) from the browser toolbar. Accept quests, complete their requirements, and claim rewards in Discord.

## Install

1. Open `chrome://extensions/` and enable **Developer mode**.
2. Select **Load unpacked** and choose the `extension` folder.
3. Click **Orbify** in the toolbar, then **Open Discord Quests**.

When upgrading from 1.0, replace the old extension folder and reload Orbify in the extension manager. If you load 2.0 from a different folder, remove 1.0 first. Then close or reload every open Discord tab to clear the old page hooks.

## Permissions

Orbify 2.0 uses a local popup with two links and requires zero browser permissions. This version removes automatic quest enrollment, simulated progress, and Discord request and client-identity modification. Quest progress and notifications are handled in Discord.
